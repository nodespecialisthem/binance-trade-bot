# Загрузка исходников и оформление v1.1.0

Документация не содержит имени аккаунта, адреса репозитория или шаблонных ссылок. Менять логины и URL в README не требуется.

## 1. Загрузка исходников

Распакуй исходный ZIP. Загрузи **содержимое папки `binance-trade-bot`** в корень своего репозитория с заменой одноимённых файлов.

В корне должны находиться `README.md`, `README.ru.md`, `LICENSE`, `requirements.txt` и папка `binance_trade_bot`. Сохрани `.user.cfg.example`, `.gitignore`, `data/.gitignore` и `logs/.gitkeep`; при переносе через Git или GitHub Desktop скрытые файлы не теряются из-за ручного выбора в проводнике.

Не загружай исходный ZIP вместо распакованных файлов: он не распакуется автоматически. Личные `user.cfg`, API-ключи, базы данных и логи не публикуй.

## 2. Заголовок и описание релиза

Открой существующий релиз **v1.1.0** и нажми **Edit**.

- В поле **Release title** вставь текст из `RELEASE_TITLE.txt`.
- В описание вставь содержимое `RELEASE_NOTES.md`.
- Сохрани изменения.

Загрузка исходников и изменение файлов `RELEASE_TITLE.txt` или `RELEASE_NOTES.md` не меняют автоматически поля уже опубликованного релиза. Их нужно обновить отдельно.

## 3. Вложения релиза

Документация рассчитана на файлы **`BinanceTradeBot.zip`** и **`BinanceTradeBot.rar`**. Внутри каждого должен находиться **`BinanceTradeBot-Windows-x64.exe`** и необходимые ресурсы твоей сборки. Пользователю достаточно скачать один формат архива.

Если публикуешь оба формата, проверь, что в них лежит одна и та же версия приложения и одинаковые необходимые файлы. После распаковки запуск приложения описан двойным щелчком по EXE.

Скрипты подготовки релиза не являются частью инструкции запуска. Если нужны конфигурация, DLL или другие ресурсы, сохрани их в архиве рядом с приложением в расположении, которое ожидает сборка. Личные ключи в архив не включай.

## 5. Что проверено в этом комплекте

Проверены целостность исходного ZIP, согласованность названий и версии в новых документах, синтаксис Python-файлов и сохранение торгового кода и лицензии. В новых README и описании релиза нет внешних ссылок или имён пользовательских аккаунтов.

Готового EXE и архивов приложения в исходном комплекте нет. Windows-сборка, установка зависимостей и работа с биржей здесь не проверялись. Зависимости сохранены из исходного проекта; может потребоваться работа над совместимостью.

Для релиза используй исполняемый файл из соответствующих опубликованных исходников. Способ сборки, исходный коммит, реально проверенные Windows и результаты тестирования укажи после проверки. Авторство и лицензия сохранены.

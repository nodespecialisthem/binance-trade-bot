# Binance Trade Bot for Windows v1.1.0 — Independent Build

Independent Windows distribution based on the open-source Binance Trade Bot project.

## Download

Expand **Assets** and choose **one** archive:

- **`BinanceTradeBot.zip`** — ZIP package.
- **`BinanceTradeBot.rar`** — alternative RAR package.

The application inside the extracted package is **`BinanceTradeBot-Windows-x64.exe`**. The executable is inside the archive, rather than a separate download.

## Extract and launch

1. Download one of the Windows application archives above.
2. Extract the complete archive to a writable folder.
3. Keep the supplied companion files together and configure the application according to `README.md` or `README.ru.md`.
4. Double-click **`BinanceTradeBot-Windows-x64.exe`** inside the extracted folder.

The automatically generated **Source code** archives contain the source files rather than the Windows application package.

## Configuration and compatibility

The source configuration template is `.user.cfg.example`; save a local copy as `user.cfg` if your build uses that format. The source template has blank credentials and `testnet=true`. Review `supported_coin_list` and your exchange environment before use.

Build-specific requirements, the source revision used for the executable, supported Windows versions, and test results must be documented by the maintainer. This description does not claim verified compatibility or new trading features.

# Binance Trade Bot для Windows

Независимо поддерживаемый вариант открытого проекта Binance Trade Bot.

## Скачать — v1.1.0

**Открой Releases → выбери v1.1.0 → раскрой Assets → скачай `BinanceTradeBot.zip` или `BinanceTradeBot.rar`.**

Выбери один формат: ZIP или RAR. Скачивать оба архива не требуется. Внутри находится **`BinanceTradeBot-Windows-x64.exe`**. Кнопка **Code → Download ZIP** и автоматически создаваемые архивы **Source code** содержат исходники, а не готовый пакет Windows-приложения.

## Распаковка и запуск

1. Скачай **`BinanceTradeBot.zip`** или **`BinanceTradeBot.rar`** из релиза **v1.1.0**.
2. Полностью распакуй его в отдельную папку с правом записи. Не запускай приложение из окна архиватора.
3. Сохрани расположение файлов настроек и других ресурсов из комплекта.
4. Настрой приложение по инструкции ниже до включения торговли.
5. Открой распакованную папку и дважды нажми **`BinanceTradeBot-Windows-x64.exe`**.

## Настройка

Для сборки, использующей формат конфигурации опубликованных исходников:

- Скопируй `user.cfg.example` под именем **`user.cfg`**. Если шаблона нет в архиве, возьми `.user.cfg.example` из репозитория и сохрани его копию как `user.cfg` рядом с приложением.
- Заполни настройки локально. В исходном шаблоне API-ключи пустые и установлено **`testnet=true`**.
- Сохрани **`supported_coin_list`** рядом с приложением и проверь доступность символов в выбранном окружении. Если файла нет в архиве, возьми его из соответствующей версии исходников.
- Осознанно задай `current_coin`: в исходной реализации пустое значение может привести к выбору и покупке монеты из списка.
- Сохрани папки **`data`**, **`logs`** и **`config`**. Создай их, если они нужны твоей сборке и не создаются автоматически.

Не публикуй API-ключи и личный файл `user.cfg`. Сначала проверь конфигурацию в тестовом окружении. Точные требования исполняемого файла зависят от способа сборки и должны быть описаны в релизе.

## Возможности исходного проекта

Python-реализация отслеживает относительные цены криптовалют и может обменивать настроенные монеты через промежуточную валюту, например USDT. В исходниках доступны стратегии, примеры конфигурации и код бэктестинга.

## Частые проблемы

| Проблема | Что проверить |
| --- | --- |
| EXE не найден | Полностью распакуй архив `BinanceTradeBot` и открой распакованную папку |
| Конфигурация не найдена | Имя `user.cfg`, отсутствие расширения `.txt` и расположение файла |
| Список монет пуст или отсутствует | Наличие `supported_coin_list` и актуальность символов |
| Ошибка записи логов или базы | Папки `logs`, `data` и права записи |
| Приложение закрывается или выдаёт ошибку | Точный текст ошибки, доступные логи, версию релиза и Windows |

Для обращения в Issues опиши шаги воспроизведения. Не прикладывай секреты и полный личный конфиг.

## Сведения о выпуске

Инструкция относится к **v1.1.0**. Поддерживаемые версии Windows, коммит исходников сборки, команды сборки и результаты проверки должен указать сопровождающий проекта в описании релиза. Наличие архива само по себе не подтверждает совместимость.

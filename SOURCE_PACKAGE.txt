ИСХОДНИКИ И ДОКУМЕНТАЦИЯ — v1.1.0

1. Распакуй ZIP и загрузи содержимое папки binance-trade-bot в корень репозитория.
2. Через Edit release отдельно вставь заголовок из RELEASE_TITLE.txt и описание из RELEASE_NOTES.md в релиз v1.1.0.
3. Прикрепи свой BinanceTradeBot.zip и/или BinanceTradeBot.rar с BinanceTradeBot-Windows-x64.exe и необходимыми файлами внутри. Если публикуешь один формат, убери строку про отсутствующий формат из описания релиза; README допускает выбор одного из двух форматов.

Пользователь скачивает архив из релиза, распаковывает его, настраивает приложение и запускает EXE двойным щелчком.

README и описание релиза не требуют замены логинов или адресов репозитория. Авторство и исходная лицензия сохранены. Полная инструкция: PUBLISH_RU.md.

В исходном ZIP нет EXE. Сборка и работоспособность Windows-приложения не проверялись.
